GAMEHUB DOWNLOADS — PACOTE PRONTO
====================================

Arquivos:
- index.html  = página pública/visitante
- admin.html  = painel do administrador
- README.txt  = instruções

IMPORTANTE:
Este pacote é um site estático. Eu não consigo criar, nesta conversa, uma URL pública HTTPS real sem acesso a uma conta de hospedagem/deploy. Por isso não vou inventar um link.

PUBLICAÇÃO:
1. Abra https://app.netlify.com/drop no Chrome.
2. Crie/entre na sua conta Netlify.
3. Arraste a pasta que contém index.html e admin.html para a área de publicação.
4. O Netlify fornecerá uma URL HTTPS pública.
5. Visitante: URL do site (ex.: https://NOME.netlify.app/)
6. Administrador: a mesma URL + /admin.html

ADVERTÊNCIA DE SEGURANÇA:
O admin.html incluído é um painel estático de demonstração. A palavra-passe inicial é admin123 e a autenticação ocorre no navegador. ISSO NÃO É SEGURANÇA DE PRODUÇÃO: alguém que entende de código pode contorná-la. Para um painel realmente privado, é necessário autenticação no servidor (por exemplo Firebase/Supabase/Netlify Identity ou backend próprio).

ADSENSE:
O Google AdSense só funciona depois de o site ser submetido/aprovado e o código fornecido pelo Google ser inserido. Não coloque anúncios de forma a violar as políticas do Google.

CONTEÚDO:
Publique somente jogos, imagens e links que você tenha autorização para distribuir. Não use o site para pirataria, cracks ou cópias não autorizadas.

CONTACTOS:
No admin, configure WhatsApp e Telegram. Os dados ficam no armazenamento do navegador nesta versão estática.
